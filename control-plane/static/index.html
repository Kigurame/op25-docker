RTL-SDR Devices

Dongle diagnostics

Runs rtl_test on the dongle for a few seconds and reports whether it can actually receive. Look for the tuner errors (PLL not locked!, r82xx_set_freq: failed) that also appear in the op25 log when a dongle cannot tune — usually a USB power / dongle hardware problem, not a configuration one.

Tip

op25 uses the rtl=<index> device argument. Match devices[0].args in cfg.json to the index shown here. USB devices must be passed to the container with --device=/dev/bus/usb (see docker-compose.yml).
